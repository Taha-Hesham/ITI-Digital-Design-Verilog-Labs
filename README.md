# ITI Digital Design & Hardware Verification Labs

A comprehensive collection of Digital System Design labs, RTL modules, and testbenches developed using Verilog HDL during the Mahara-Tech ITI workshop. This repository demonstrates a progression from basic logic gates to a fully verified hierarchical digital system.

## 📂 Repository Structure

* **Lab 1:** Basic Logic Gates (AND/OR)
* **Lab 2:** Multiplexer (Mux) & Full Adder implementations
* **Lab 3:** D Flip-Flop & Johnson Counter
* **Lab 4:** 7-Segment Decoder & Decimal-to-Binary Encoder
* **Lab 5:** ALU Integration & Keypad interfacing with 3 Seven-Segment displays
* **Lab 6:** Counter to Decoder & Seconds Counter
* **Lab 7:** One-Hot Counter & BCD Finite State Machine (FSM)
* **Final Project (ITI_BQS):** A complete Bank Queue Management System featuring hierarchical RTL modules (FSMs, up/down counters, wait-time ROM) and comprehensive ModelSim testbench verification for synchronous timing, edge detection, and corner cases.

## 🛠️ Technologies & Methodologies

* **Hardware Description Language (HDL):** Verilog
* **Simulation & Debugging:** ModelSim
* **Design Concepts:** RTL Modeling, Synchronous/Asynchronous Design, Finite State Machines (FSM), Pipeline Latency
* **Verification:** Testbench Architecture, Corner-Case Testing, Timing Analysis
